# AI Work Playbook

1. Start by reporting repo, branch, upstream, dirty files, and active run.
2. For a new topic, create or reuse `codex/<topic-slug>` and create `.ai/runs/<run-id>/`.
3. Keep `.ai/HANDOFF.md` current with the latest branch, run, validation, and next step.
4. Commit small checkpoints after meaningful progress. Push when an origin remote is configured.
5. On resume, read `.ai/HANDOFF.md`, `.ai/ACTIVE_RUN`, and the active run folder before editing.
