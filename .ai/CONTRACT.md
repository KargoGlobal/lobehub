# AI Work Contract

- Use `ai-work status` at the start of each session.
- Use `ai-work start "topic"` before beginning a new or resumed topic.
- Use `ai-work checkpoint "message"` before pausing, switching laptops, or handing off.
- Keep branch names under `codex/<topic-slug>` unless the repository has a stricter convention.
- Never commit secrets, credentials, tokens, private keys, or machine-local config.
- Never force-push or rewrite shared history without explicit approval.
