# AI Work Rubric

Before DONE or checkpoint handoff, verify:

- Scope is clear and the active branch matches the topic.
- Relevant tests, lint, or build checks were run or explicitly skipped with a reason.
- `.ai/HANDOFF.md` explains current state and next steps.
- Git status is clean after checkpoint, unless uncommitted work is intentionally called out.
- No secrets or local-only artifacts are staged.
